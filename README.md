# 无尽强化 · Rogue FPS

> 0.2.0 发布候选：最新安装、操作和规则请阅读 [RELEASE_GUIDE.md](RELEASE_GUIDE.md)。下方为历史原型说明，阶段枪械进化与旧波次规则已停用。

在 PyCharm 打开本文件夹，选择安装有 pygame 的 Python 解释器，运行 `fps_game.py`。
首次安装依赖请在 Terminal 中执行 `python -m pip install -r requirements.txt`。

## 玩法

地图为 26×26 的开阔空地，仅保留外围边界，玩家在中央出生。清除当前波次，2.5 秒后进入下一波，没有最终波数上限。红色为普通敌人，橙色疾跑敌人移动更快，蓝色射手从第二波开始发射可躲避弹丸，紫色重装敌人每五波出现，生命和近战伤害更高。
击杀获得经验，升级后暂停战斗并随机展示三项强化。按 1、2、3 或点击卡片选择。强化可重复叠加，本局死亡后全部重置。
强化包含伤害、射速、生命、移动、弹匣、换弹、再生、击杀回血、贯穿和范围爆破，可组合构筑。
每波开始补充弹药并装满弹匣。敌人数量最多同时 24 个，以保持性能；生命与伤害随波次持续增长。

## 操作

- WASD 或方向键移动；Shift 冲刺；鼠标左右和上下瞄准。
- 按住左键持续开火；R 换弹。
- ESC 暂停/继续；暂停时 R 重新开局。
- 强化界面按 1/2/3 或鼠标选择。
- 死亡后 Enter 或 R 重开；Q 或关闭窗口退出。
- M 开关音效。开火、命中、换弹、升级和敌人射击音效由程序生成，无需下载素材；无音频设备时仍可运行。

玩家武器为即时命中，亮黄色轨迹用于显示射击方向；敌人橙红弹丸有实际飞行时间，可以通过横向移动躲避。

命中判定使用敌人模型的可见像素，准星对准血条、身体间隙或空白不会扣血。爆破强化会对直接命中目标附近的敌人造成范围伤害。
升级卡片带程序绘制图标。选择“枪械进化”提升枪械等级：3 级突击步枪提高射速，6 级磁轨步枪增加贯穿与伤害，9 级爆裂核心增加爆破与射速；后续枪械强化仍可叠加。每三级升级保证有枪械进化选项。
每 5 波生成紫色精英（三发扇形弹），每 10 波生成红色 Boss（五发弹幕、半血后射击加速），Boss 波替代该波精英。Boss 有顶部独立血条，击杀精英/Boss 分别奖励 5/12 经验。

无需插件、账户或外部素材。当前使用 pygame 的射线式场景渲染，属于可运行原型。
