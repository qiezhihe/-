阶段更新：8+武器索引越界已修复，槽位合同已通过；Space 跳跃、刀盾近战/减伤、宠物冷却、terrain_blocks 和 wave_start 已接入。通过 `wave_wait=now-1` 触发真实波次转换后，扩展合同 9 项和旧 `test_game.py` 42 项共 51 项全部通过（10.744 秒）。

扩展连续推进：`qa_progression.py` 完成 150 波、174 张强化卡、145 级，实际槽位自然获得武器 `[0, 4, 6]`，射速下限 35 ms，耗时 0.47 秒。因新武器目录超过旧绘制数组，QA 脚本在绘制前暂将 index≥4 回退到 0；这是测试兼容措施，主程序的 8+武器绘制仍需程序员补齐并另行回归，不能据此宣布所有新枪美术完成。

- `rogue_content.py`: `C11D92D445AEDF204FA7B487D2EA6CD0575AB016C3C069985E293210685F30F7`

最终 39 项自动回归全部通过，7.734 秒；当前 hash 100 波 / 12,000 帧 / 1,200 绘制采样耗时 6.91 秒，绘制平均 5.11 ms、P95 7.12 ms、最大 11.24 ms。连续 150 波奖励流程同 hash 通过，170 次选卡、141 级、四枪自然解锁，耗时 0.44 秒。最后一次 500 波 / 300,000 帧长测耗时 231.93 秒，绘制平均 7.23 ms、P95 14.62 ms、最大 43.52 ms，最大弹丸 14，无断言或崩溃。该长测载入 `F87578AA8F4F30AEDCF3791C99DA4D72EB8244E1329CC0E594CA6DCFEFD00460` 主程序快照，最终追加俯仰轨迹对齐、尾迹缩短/光晕降低，以及每次开火复用敌人 mask/距离/视线缓存；最新快照回归、中测、奖励流程通过。

截图 `qa_screenshots/close_melee_bullet_low_ammo.png` / `sniper_ads_boss_hud.png` / `boss_rewards.png` 已实际打开检查。20 颗弹丸近身、近战蓄力、25 生命 / 2 备弹场景可读；Boss 顶部血条独立，狙镜不遮 HUD，三选一文字不裁剪。最后降低弹丸尾迹和光晕后敌人躯干更可见。

测试目标为当前 Python / pygame 项目，不适用旧 Godot / Unity 文档。

新增 `test_game.py`：38 项自动回归，最近一轮全部通过（8.077 秒）。覆盖玩家移动和边界、相对运动弹丸擦身/直接命中、脱靶/可见像素命中、贴脸目标不吞掉远处攻击、波次清弹、Boss 每 5 波、射手数量上限、备弹上限/补给距离、武器解锁/专属强化过滤、装填守恒、反复选择同枪/属性升级保持换弹、Boss 奖励稀有度抽样、DOT 死亡不攻击、暂停倒计时冻结、ADS 清除、静音和重开状态、所有强化应用和多界面绘制、Q 退出。追加真实事件循环菜单开始/失焦/暂停 R/数字切枪、未聚焦强化不恢复战斗、DDA 与 300 组解析矩形交点对照、开镜视野边缘投影一致、极端霰弹/射速/装填/弹匣上限、攻击装饰像素不算命中、异常释放图形设备、无声音设备和坏字体回退。四枪 PCM 内容和长度不同；暂停装填不前进；死亡优先于回血/波次/同帧 DOT 奖励；暂停右键不开镜。

新增 `qa_soak.py`：初次 100 波、12,000 逻辑帧、1,200 绘制帧采样通过。绘制平均 10.50 ms，P95 17.52 ms，最大 21.43 ms，最大同屏弹丸 14；每帧检查备弹和弹匣上限。该结果使用 SDL dummy 驱动，不代表真实窗口帧率，也不验证实际听感。

旧版长测：500 波、300,000 逻辑帧、30,000 绘制采样无崩溃，耗时 445.64 秒，绘制平均 13.87 ms / P95 26.14 ms / 最大 49.43 ms。DDA 新版同规模长测：500 波、300,000 帧、30,000 绘制采样无崩溃，耗时 203.80 秒，绘制平均 6.33 ms / P95 12.70 ms / 最大 31.09 ms，最大弹丸 14。两次长测均为内存加载后的代码快照；新版长测先于最终死亡时序修复，最新代码另以 38 项回归和连续 150 波验证。dummy 驱动下的性能不等于真实硬件窗口 FPS。

新增 `qa_progression.py`：连续完成 150 波真实波次/经验/奖励状态转换，自动选择 170 张卡，到达 141 级且四枪自然解锁；新波清除弹幕、弹药上限全程正常。为加速测试，只注入敌人死亡并快进 3 秒展示，实际调用 finish_kills / choose_upgrade / update 完成后续波次；没有直接调用 spawn_wave 跳过升级流程。最新耗时 0.57 秒。

已向程序员报告并由其修复：重复同枪/强化取消装填、Boss 奖励被低级武器卡覆盖、ADS 状态粘住、死亡 DOT 敌人继续攻击。继续检查升级界面失焦与长局耐久。

复现命令：`py -m unittest -v test_game`；`py qa_soak.py --waves 500 --frames 600`；`py qa_progression.py`。
