# 游戏程序员汇报

当前项目实际为 Python 3 + pygame 射线 FPS，旧岗位说明中的 Godot 不适用。

本轮修改由游戏程序员独占 `fps_game.py`，与内容员工和 QA 交叉复核。

已完成：

- 开始菜单、版本标识、按键说明与按钮；波次三秒自动开始继续保留。
- 波次提示也可 Esc 暂停，倒计时冻结；失焦自动暂停，鼠标释放、ADS 重置；重开保留静音。
- 同枪切换及升级不取消进行中的装填；换武器取消当前装填但不凭空返还/扣除备弹。
- DOT 致死的敌人不再同帧攻击，死亡时清理其效果和动画；空场射击不反复推迟下一波。
- Boss 奖励不再被蓝色武器解锁卡覆盖，普通升级继续 25% 概率出现具体解锁卡。
- 精确网格射线替代细小步进，墙面与 ADS 使用一致的缩放角度。
- 射击判定排除蓄力弧、挥击弧和枪口火焰装饰，脚下阴影不进入命中图。
- 为四枪增加接收机、握把、弹链箱、狙镜和枪栓以及手持轮廓；远景山峰、太阳、敌人护甲细节与低备弹补给方向提示。
- Boss 正上方独立面板带生命数值，HUD 下移；狙镜遮罩不会挡住生命弹药 HUD。
- 强化卡按实际像素换行，长标题缩放，升级图标按医疗/防御/元素/弹药/速度等机制区分。
- 运行保护：移速最高 8，最小开火间隔 35ms（含快攻），最小换弹 250ms，弹匣最高 500，霰弹最多 64 弹丸。
- 命中 X 与击杀浮字；主循环异常通过 finally 释放鼠标并关闭 pygame。
- 生命归零优先进入死亡态，回血和 DOT 奖励不会覆盖死亡；强化三选一按效果去重，护盾显示于 HUD；重开在播放音乐前应用静音设置。
- 修正抬头/低头的玩家射击轨迹垂直投影，准星与弹道端点一致。
- 敌弹尾迹最长 100 像素、最宽 6 像素，降低近身光晕遮屏，保留醒目亮芯和危险提示。
- 每次射击缓存敌人的身体命中图、距离与视线，多个霰弹复用缓存；不会复用到下一次射击，动画仍准确。

验证依据：`py -m py_compile fps_game.py`；dummy 视频/音频驱动测试了菜单、波次、暂停恢复、开镜、同枪装填保持、升级卡绘制。60 帧 CPU 绘制均值约 5.1ms（无窗口驱动，不能等同实际帧率）。离屏截图位于 artifacts，最终功能回归由 QA 员工复核。

进一步验证：38 项 `test_game` 自动回归全部通过（8.689 秒）；150 波真实状态/奖励推进（击杀注入）通过，选择 170 张卡、141 级、四枪均解锁且没有奖励链死循环。故障注入证明音频设备不可用仍能启动/射击/绘制，字体候选加载失败会回退默认字体；绘制抛异常后 pygame 未初始化，证明退出清理执行。默认字体不保证中文字形。

最终轨迹数学修复后 38 项回归再过（8.830 秒），pitch -0.35 / 0 / +0.35 的轨迹投影与屏幕中心垂直偏差不超过 1 像素。

弹幕视效收敛后的最新 39 项回归全部通过（9.763 秒）；额外 10 次连续重开、静音保持、Boss 奖励选择和死亡循环通过。

最终命中图缓存修复后 39 项回归再次全部通过（7.643 秒）。故意构造 64 弹丸 × 24 个贴脸 Boss 极端场景，单次射击耗时由 357.5ms 降至 6.9ms；这是本机无窗口 CPU 比较，实际帧率另需设备检查。

限制：仍为程序几何的 2.5D pygame 原型；没有将截图测试描述为真实设备手感或音效听感测试。
