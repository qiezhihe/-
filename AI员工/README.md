# FPS AI 员工目录

当前可运行项目使用 Python 和 pygame，入口 fps_game.py，内容 rogue_content.py。旧岗位模板中 Godot/GDScript 指示已过时，应以 PROJECT_CONTEXT.md 和当前派工为准。每个子文件夹代表一名 AI 员工，`总管` 文件夹负责统一派工、收集汇报和维护进度。

使用方法：打开员工文件夹中的 `AGENT.md`，复制其中的岗位提示词和当前任务，发送给对应的 AI 对话；员工完成后，把结果保存到该文件夹的 `REPORT.md`，再由总管审核。

员工目录：

- `总管/`
- `游戏设计师/`
- `游戏程序员/`
- `敌人AI程序员/`
- `关卡设计师/`
- `美术资源管理员/`
- `QA测试员/`
- `发布文档员/`
